# Google-Play-Store-App-Insights
Project Overview

This project analyses Google Play Store applications and user reviews using Microsoft Power BI to identify factors influencing app popularity, ratings, and user sentiment.

Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Cleaning and Transformation
- Data Visualization
- Sentiment Analysis

Project Objectives

- Identify factors associated with app success.
- Compare free and paid applications.
- Analyse ratings across app categories.
- Examine the relationship between installs and ratings.
- Understand user sentiment through reviews.
- Provide data-driven business recommendations.

Key Findings

- Analysed 9,658 unique applications.
- Examined 37,432 labelled user reviews.
- Found that 92.2% of apps were free.
- Identified an average app rating of 4.17.
- Found a weak correlation of 0.04 between installs and ratings.
- Compared user sentiment across rating groups.

Business Recommendations

- Monitor user feedback to identify recurring complaints.
- Focus on user experience rather than installs alone.
- Evaluate pricing strategies for paid applications.
- Explore high-demand app categories.
- Use ratings and sentiment analysis to support product decisions.
